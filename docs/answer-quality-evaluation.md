# 답변 품질 평가

검증일: 2026-08-05

이 평가는 하이브리드 검색 지표와 별도로, 실제 챗봇 답변이 검색 근거 안에서
질문을 설명하는지 확인한다. 사용자 요청 경로에서는 실행하지 않으며, 개발·릴리스
검증 시에만 실행하는 오프라인 배치 도구다.

## 평가 범위

`app/data/answer_quality_eval.json`의 고정 질문마다 다음을 평가한다.

- 근거 충실도: 답변의 중요한 주장이 검색 문서에 근거하는지
- 문맥 관련성: 질문에 답하거나 적절히 거절하는지
- 챗봇 범위 준수: 개인별 납입 가능액·세액공제액·환급액을 계산하지 않는지
- 환각 위험: 근거보다 구체적이거나 근거에 없는 주장이 있는지
- 기대 동작: 정책 설명, 진단 안내, 모호성 확인, 범위 밖 질문 거절 중 해당 동작을 수행하는지

판정 모델은 질문·검색 근거·챗봇 답변을 모두 신뢰하지 않는 데이터로 취급한다.
평가 점수는 자동화 보조 신호이므로, `FAIL` 사례의 최종 판단은 출처 원문과 함께
사람이 검토한다.

## 실행

RAG 지식베이스를 먼저 적재하고 OpenAI API 키를 설정한 뒤 실행한다.

```powershell
python scripts/evaluate_answer_quality.py
```

명령을 실행한 백엔드 터미널에 각 사례의 `PASS`/`FAIL`, 근거 충실도, 관련성,
범위 준수, 환각 플래그와 요약이 출력된다. FastAPI 서버 창에서 자동으로 실행되지는
않는다. 서버를 실행한 터미널에서 별도 명령으로 실행하거나 다른 백엔드 터미널에서
실행하면 된다.

자세한 결과를 JSON 파일로 남기려면 출력 경로를 명시한다.

```powershell
python scripts/evaluate_answer_quality.py --output .\tmp\answer_quality_report.json
```

기본적으로 `OPENAI_CHAT_MODEL`을 판정 모델로 사용한다. 평가 모델을 별도로 바꾸려면
다음처럼 지정할 수 있다.

```powershell
python scripts/evaluate_answer_quality.py --judge-model gpt-4o-mini
```

각 사례는 답변 생성, 검색 임베딩, 판정 호출에 API 비용이 발생할 수 있다. 실제 사용자
대화·계좌정보를 평가셋에 넣지 말고, 점검된 고정 질문만 사용한다.
