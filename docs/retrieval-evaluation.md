# 하이브리드 검색 평가

검증일: 2026-08-05

`app/data/retrieval_eval.json`의 고정 질의 9건(법령 1건, 숫자 5건,
일반 1건, 범위 밖 2건)을 실제 PDF 인덱스 907개 청크에서 평가했다.
임베딩은 `text-embedding-3-small`, `top_k=4`, 후보 수는 12이며 로컬 RRF
재정렬을 사용한다.

| 지표 | 벡터 기준선 | 하이브리드 |
| --- | ---: | ---: |
| Recall@4 | 0.7857 | 0.7857 |
| Hit rate@4 | 0.8571 | 0.8571 |
| MRR | 0.6905 | 0.8571 |
| 범위 밖 no-answer 비율 | 1.0000 | 1.0000 |

하이브리드 검색은 Recall@4와 범위 밖 질의 거부율을 유지하면서 MRR을
0.1667 개선했다. 숫자와 법령 조문을 정규화한 BM25와 RRF는 결정론적으로
동작하며, 정확한 법령 조문 일치만 벡터 상위 결과보다 승격할 수 있다.

다음 명령으로 같은 평가를 실행할 수 있다. 실제 임베딩 API를 호출하므로
유효한 환경변수와 미리 구축한 ChromaDB 인덱스가 필요하다.

```powershell
python scripts/evaluate_hybrid_search.py --top-k 4
```
