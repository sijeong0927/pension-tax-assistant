# RAG 답변 품질 평가 결과

일반 사용자 질문 20개 기반 1차 평가

2026-08-05

---

## 왜 답변 품질을 평가하나

- 검색 지표가 좋아도 실제 답변이 근거를 벗어나거나 질문을 오해할 수 있다.
- 우리 챗봇은 정책·조건 설명과 진단 화면 안내를 담당한다.
- 개인별 납입 가능액, 세액공제액, 환급액을 챗봇이 계산하지 않도록 점검한다.

---

## 평가 방법

일반 사용자가 묻기 쉬운 연금저축·IRP·ISA 질문 20개를 고정해 반복 실행한다.

```text
질문 → Hybrid RAG 검색 → 답변 생성 → 자동 판정 → 실패 사례 검토
```

자동 판정 항목

- 근거 충실도
- 문맥 관련성
- 정책 범위 준수
- 환각 여부
- 기대 동작 수행 여부

---

## 1차 결과

| 지표 | 결과 |
| --- | ---: |
| 전체 통과 | **10 / 20 (50%)** |
| 환각 플래그 | **8건** |
| 근거 충실도 평균 | 4.25 / 5 |
| 문맥 관련성 평균 | 4.35 / 5 |
| 정책 범위 준수 평균 | **3.80 / 5** |

> 답변이 검색 근거와 대체로 관련은 있었지만, 챗봇 역할을 벗어난 응답이 반복됐다.

---

## 어떤 동작에서 실패했나

| 기대 동작 | 통과 | 해석 |
| --- | ---: | --- |
| 정책 설명 | 10 / 16 | 기본 정보는 절반 이상 대응 |
| 개인별 계산 요청 → 진단 안내 | **0 / 2** | 한도·공제율 설명으로 흘러감 |
| 모호한 질문 → 재질문 | **0 / 1** | 계좌·행동을 확인하지 않음 |
| 범위 밖 질문 → 거절 | **0 / 1** | 무관한 세금 답변을 생성 |

---

## 실패 사례 1: 개인별 계산 요청

**사용자 질문**

> “연금저축에 이미 넣은 돈이 있는데, 저는 얼마를 더 넣으면 세금을 얼마나 돌려받나요?”

**기대 동작**

- 챗봇은 계산하지 않고, 진단 화면으로 이동하도록 안내

**실제 문제**

- 일반 한도와 공제율을 길게 설명함
- 사용자가 원하는 다음 행동을 제시하지 못함

---

## 실패 사례 2: 범위 밖 질문

**사용자 질문**

> “서울의 내일 날씨와 미세먼지를 알려 주세요.”

**기대 동작**

- 연금·세금 상담 범위 밖임을 짧고 명확하게 안내

**실제 문제**

- 검색 근거가 없는데도 세금·공제 안내 문구를 생성함

---

## 실패 사례 3: 핵심 조건 누락

**사용자 질문**

> “연금저축에 넣은 돈은 몇 살부터 받을 수 있어요?”

**실제 답변의 문제**

- 55세만 언급
- 최초 가입일부터 5년 경과 조건을 빠뜨림

**시사점**

- 검색된 문서에 핵심 요건이 포함됐는지, 답변이 그 요건을 빠뜨리지 않는지 함께 봐야 한다.

---

## 판정 점수도 보정이 필요하다

일부 실패는 답변 자체보다 판정 기준이 과도하게 엄격해서 발생했다.

- 법정 납입 한도·공제율 같은 **일반 정책 수치**도 개인 계산으로 오인
- 일반 정책 설명과 개인별 금액 계산을 판정 기준에서 명확히 분리해야 함
- 따라서 50%는 현재 품질의 중요한 경고 신호이지만, 최종 정확도 수치로 단정하지 않는다.

---

## 개선 우선순위

1. **검색 근거 없음**: 고정된 범위 밖 안내를 반환
2. **개인별 계산 의도**: 진단 화면 바로가기와 함께 계산을 이관
3. **모호한 표현**: 계좌 종류와 행동(이전·해지·전환)을 재질문
4. **핵심 요건 답변**: 검색 문서·프롬프트에서 필수 조건 누락 방지
5. **판정 기준 보정**: 일반 정책 설명을 개인 계산으로 오인하지 않도록 수정
