기준일: 2026-08-05

## 반영 원칙

- 질문·답변·조건·출처를 하나의 RAG 청크로 저장한다. 답변만 별도 청크로 저장하지 않는다.
- 기존 FAQ와 결론이 겹치는 경우에는 새 FAQ의 범위를 좁히고 관련 FAQ를 답변에서 연결한다.
- 세법 수치가 귀속연도에 따라 달라질 수 있는 문항은 질문 또는 답변에 기준연도를 명시한다.
- 모든 신규 FAQ에는 공식 1차 출처의 제목·URL·기준일·검증일을 넣었다. 상품 분류가 필요한 경우에는 금융회사 설명서 확인을 안내한다.

## 대화에서 확인할 최소 프로필

- 공통: `tax_year`, 근로·사업 등 소득 유형, 총급여 또는 종합소득금액
- 가족: 관계, 나이·출생연도, 소득 요건, 자료제공동의 여부, 중복공제 여부
- 연금·ISA: 계좌 종류, 납입일·납입액, ISA 유형, 금융소득 종합과세 이력
- 주택: 무주택·세대주 여부, 주택 취득 시점·기준시가, 대출 명의·기간·상환 방식
- 증빙·사후정정: 영수증 보유·간소화 조회 여부, 원래 신고한 귀속연도, 환급·보전금 수령 여부

## 반영 전·후 확인

- `python -m json.tool app/data/tax_faq.json`
- 엄격 출처 검증을 포함한 지식베이스 로드 테스트
- 기존 질문과 신규 질문의 정확한 중복 여부 확인
- 답변에서 귀속연도와 예외 조건이 빠지지 않았는지 검토
